# 司马八字 · 十神（主星/副星）3D资产制作说明

## 设计说明

十神是命盘固有的静态事实（不会随时间变化），所以这批资产**不做时间衰减/维护机制**，每个十神只需要**一个**模型，点击后展示命理讲解，不需要3档状态。

十神一共10个，天然分成5对——每对"同源不同性"（同一种能量，一个偏"正/稳"、一个偏"偏/烈"）：

| 分组 | 正（主星，更稳/更规矩） | 偏（副星，更烈/更不按常理） |
|---|---|---|
| 比劫 | 比肩 | 劫财 |
| 食伤 | 食神 | 伤官 |
| 财星 | 正财 | 偏财 |
| 官杀 | 正官 | 七杀 |
| 印枭 | 正印 | 偏印 |

视觉设计上，每一对用**同一个物件领域**（比如"财星"这一对都是黄金），但处理手法呼应"正=规整安稳"vs"偏=不按常理/更有冲击力"这条轴——延续五行系统"nourish=不足/规整 vs restrain=过剩/失控"那套设计逻辑，不是简单换个颜色应付。
