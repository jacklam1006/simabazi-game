## 长期悬而未决的跨领域契约（每次改动前主动核对）
1. **哈希算法一致性**：`js/bazi-analysis.js` 与 `js/tutorial.js` 的 `_computeHash` 是两处独立实现同一算法，任何一处改动必须同步另一处
2. **API字段名契约**：历史上 `file_token`→`image_token`、`model_url`→`model` 都曾因前后端改名不同步而出故障，backend-service 与 frontend-3d/bazi-pipeline 任何一侧改字段名都要通知另一侧
3. **PROMPT_SYSTEM.md 修改记录**：提示词相关文件改动必须同步追加记录表格，否则该文档会逐渐失真
4. **部署手册.md 时效性**：部署配置（环境变量、端点、套餐）改动必须同步更新，否则该文档会逐渐失真
